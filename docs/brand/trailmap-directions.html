00

What the sheet is doing

Look past the pen work and the map is four decisions, none of which the current site makes.

It’s a network, not a list — trails branch, rejoin, and have names like Screamer and Una’s Surprise. It’s two-sided: unfold it and the reverse gives you the key plus one trail described at length. It talks to you — the Black 10 gets a hand-written paragraph that says it’s one-way, that the cut-offs are few, and that you should move aside if you’re skiing it beyond your abilities. And what you have is someone’s copy: creased into eighths, tacked to a wall with blue putty, kept.

“If you are a competent intermediate desiring a challenge, go for it — but exercise caution. This trail requires commitment. It is one way and there are only a few untracked cut-offs.”

That paragraph is a race review. It rates a course, states the risk, and tells you what to do — which is exactly what 229 profiles are for. The map isn’t just a look to borrow. It’s a working model of the product.

the database stops being a table

What it buys you: the shape of the sport becomes visible. Worldloppet is one big marked loop with five tier-one races on it. Swiss Loppet is a tight local circuit of seven, none above 60. Russialoppet is a nine-race spur that touches nothing else. You cannot see any of that in a sorted table, and it is all true.

The table doesn’t die — it stays as the sortable, searchable, crawlable view. The network becomes the way people browse, which is what they actually do on a race database.

02

The Groomer’s Note

the Black 10 paragraph as a content model

The best writing on the map is a hand-lettered block in the bottom corner describing one hard trail — what it is, what it costs, and one instruction. Make that the spine of every race page and the scores become supporting evidence instead of the headline.

The Birken is not a technical race. It is a long one, in a place where the weather decides. Fifty-four kilometres from Rena, up onto the ridge at 900 metres where there is no shelter at all, then down into Lillehammer.

You carry 3.5 kilos the whole way. That is the race — not the distance, the pack, and the hour you spend above treeline in March carrying it.

Ten thousand people start and the tracks will be good; grooming here is as reliable as it gets anywhere. What ends days is the top. Skiers who are strong enough for the climb get cold on the plateau and lose the descent. Dress for the ridge, not for the start pen. If it is blowing hard the organisers will move the route down, and you should be glad when they do.

Do not make this your first marathon.

The cost is real: 229 of these have to be written, and a generated one would be obvious within two sentences. The honest version ships the note on the races you can speak to and leaves the rest on the current structure — with the empty state saying so, rather than filling it with prose nobody stands behind.

03

The Fold-Out

two-sided, not infinite-scroll

The sheet is folded into panels and you open the one you need. A race isn’t a new page you navigate to — it’s the next panel, unfolding beside what you were already looking at, with the key staying visible the whole time.

Birkebeinerrennet. 54 km, classic, 1,050 m. The note, the scores, the sources — opened beside the map you came from, not instead of it.

Honest risk: this is a metaphor that can fight the browser. Back button, deep links, and screen readers all assume pages. Done properly each panel is still its own URL and the fold is presentation only — done lazily it’s a single-page app that Google can’t crawl, which for a database that lives on search traffic would be self-harm.

04

Someone’s Copy

provenance you can see

What you photographed isn’t a map, it’s a map — folded into eighths, tacked up with blue putty, corner going soft. The site’s hardest claim is that a person checked these races. So let the page carry the marks of having been checked: a stamp with a real date, a note in the margin, wear where it’s been handled.

The discipline that keeps this from being scrapbooking: every mark is a field. The stamp is the verification date. The margin note is a real correction from the fact-check pass. The dog-ear only appears on races you’ve opened before. No wear that isn’t earned — otherwise it’s a filter, and a filter on a site that sells accuracy is a bad joke.

05

These aren’t A, B and C

They’re four separable moves. You can take one, or three, and they compose — the network is the browse surface, the note is the read surface, the copy is the treatment on both.

What it changesEffortRisk
The Network Browsing 229 races. Makes the sport’s structure visible for the first time. One new generator + a layout pass. The data already exists. Low. It sits beside the table, not instead of it. Ship first
Groomer’s Note What a race page is for. Scores become evidence under a judgment. Template is a day. The writing is the project. Medium — a fake note is worse than no note. Ship first
Someone’s Copy The treatment on everything. Provenance becomes visible instead of claimed. Tokens plus a stamp and wear component. Low, if every mark stays tied to a field. Ship first
The Fold-Out Navigation itself. The most distinctive and the most load-bearing. Real work: routing, history, crawlability. High. Gets between Google and 229 pages. Prove later

My recommendation: 01 + 02 + 04. Network as the browse surface, the note as the race page, the copy treatment as the skin over both. That’s a site that looks like your map and works like it. Hold the fold-out until the rest is live and you can A/B it without risking search traffic.

06

How the port runs

  1. Tokenstokens/tokens.css to the paper palette. All fifteen generators already import it, so the ground changes everywhere on commit one.
  2. trailkey.pyThe shared vocabulary: glyph defs, climb-ladder builder, legend block, difficulty mapper, stamp and wear components. One source, fifteen consumers.
  3. network.pyReads series_membership, lays out the trails, emits the SVG at build time. Static file, no client-side layout, crawlable node labels.
  4. Race pagesgenerate_race_pages.py — note slot, ladders, stamp. The note slot degrades to the current structure where no note exists, and says so.
  5. Homepage and searchNetwork as the browse surface, table kept beneath it. Copy the search files into output/search/ — the deploy reads from there, not web/.
  6. The other elevenCoaching, consulting, apply, intake, questionnaire, plans, success, confirmation, guide, legal, prep kit. Then feeds and OG images.
  7. GuardsToken-only hex rule; a legend test that fails if a glyph renders without a backing field; a wear test that fails if a stamp renders without a verification date.

The 7,987-test suite stays green throughout. BRAND_GUIDELINES.md is rewritten in the same commit as the tokens, so the spec never lags the code.
