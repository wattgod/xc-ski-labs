# Checklist

Lessons and what's included, as a packing checklist.

- **Build:** `paper` with a 2px ink outline. The header bar is ink with ground text (`list-head`). Module lists have a `panel` header. Rows are 17/600 on 1px dashed `rule` lines, each with an 18px checkbox.
- **Checkboxes:** a dotted outline is planned, a solid outline is current, and filled with a check is done.
- **Planned:** a dotted `rule` checkbox.
- **Done:** a `done` checkbox with a solid border and a ✓ in `on-done`, plus the word "Done" at the right of the row. In forced colours the border and check remain.
- **Current:** the row is filled `splash`, with a solid checkbox and the word `Now`. Focus inside it uses `on-splash`. This is the screen's one salmon object; the preview shows it inside the course.
- On sales pages, every row is planned and nothing is salmon.
- One italic note may follow the lists.
