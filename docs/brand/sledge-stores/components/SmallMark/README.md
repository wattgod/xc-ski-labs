# Small mark

At 16px the main mark's swept tips blur away and the two skis read as a plain X. Best Made Co.'s logo is a red X, so the favicon is the place where the mark is most at risk.

The small mark is drawn for 16 to 32px only. It is still two crossed skis, but they cross low, near the tails, in the herringbone V a skier uses to climb. The tips hook outward. It keeps the fjord colourway: navy tile, one wool ski on the left and one salmon ski on the right.

- **Status:** approved by Matti, 2026-11-14. File: `logos/xc-mark-small.svg`. `xc-crossed-skis.svg` stays the live favicon until the new mark ships.
- **Use:** favicons and app icons from 16 to 32px. Everywhere else, use the main mark.
- **Checked:** rendered at 16, 32 and 48px. At 16px it reads as a V with hooks, not an X.
- **Not checked:** browser tabs in dark mode, Windows high-contrast mode, and an iOS home-screen icon.
