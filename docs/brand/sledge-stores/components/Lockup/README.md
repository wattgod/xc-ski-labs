# Lockup

The mark plus `XC SKI LABS` in Big Shoulders Text 800, tracked .2em.

- **On a strap** (header and footer, `strap` fill): the wool colourway at 44px in the header and 36px in the footer (`.xc-lockup--sm`), with `on-strap` text. Nav links go right: `nav` style, 44px tall, uppercase. Hover and the current page are a 2px underline in `on-strap`; the colour never changes. Under 520px the wordmark drops to 19px and the nav wraps below.
- **On wool or oat:** the fjord colourway.
- Never put the mark on salmon. Never use a colourway other than wool and fjord.
- The wordmark carries the accessible name; the mark is `aria-hidden`.
- Not specified yet: the phone menu for more than four links, and single-colour lockups.
