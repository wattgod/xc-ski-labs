# ShippingTag

One note per tag: after-you-pay steps, refunds, access.

- **Build:** `tag-paper` with `on-tag` text in `body`. The top corners are cut, with an eyelet near the top and a dashed inner stitch at 35%.
- Long words and the email address wrap anywhere (`overflow-wrap: anywhere`), so a tag fits at 320px.
- Three across, on a `panel` band. The second and third tilt +1.2° and −1°; all three sit straight below 860px.
- **Copy:** quote the live text exactly. The refund tag names gravelgodcoaching@gmail.com as plain text.
