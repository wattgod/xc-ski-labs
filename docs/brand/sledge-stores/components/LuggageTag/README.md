# LuggageTag

One stat line, hung off a crate.

- **Build:** `tag-paper` with `on-tag` text in `tag` style (16/600 Big Shoulders Text, sentence case). The left end is arrow-cut, with an eyelet in the panel colour and a 2px `on-tag` ring. Focus inside a tag uses `on-tag`. In forced colours the tag keeps a 2px border.
- One tag per crate, between the description and the button.
- Its text is a count with what it counts: "3 lessons, 14 clips, plus the basics."
