# Button

One button. It is found by its shape, not by a colour of its own.

- **Primary:** an `action` (navy) slab with `on-action` text in `button` style (19/800 uppercase). It has a 3px border and a 5px salmon underline inside (`stroke-underline` in `splash`). It is 56px tall and full width inside crates.
- **Hover:** fills with `ground` and gets an ink border and ink text (150ms).
- **Focus:** a 3px `focus` ring with a 3px offset.
- **Disabled:** 45% opacity.
- **In dark (Fjord):** the slab is wool with navy text. The salmon underline is decoration (2.2:1 on wool), never the only cue.
- **On the salmon crate:** a navy slab with `on-splash-action` (wool) text in both themes, and no underline, because salmon on salmon disappears.
- **Quiet link:** underlined ink text, 44px tall. Use it for terms and secondary routes.
- **Label:** a purchase button gives a verb, the thing and its price: "Buy Classic, $29". Other buttons give a verb and an object. Never stencil type, and never a salmon fill.
- Not specified yet: the loading state.
